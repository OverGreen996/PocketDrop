# PocketDrop 1.0.5 — Windows 線上更新

- 啟動時自動檢查新版；設定頁也提供「檢查更新」。
- 有新版時顯示版本與說明，按「是，更新」後才下載；按「稍後」不下載。
- 下載顯示進度，以固定公鑰驗證更新包與簽署版本後，原地更新程式並重新啟動。
- 保留配對、設定與資料；更新前保存未分享的文字草稿。檔案下載中會先要求完成或取消。
- 沒網路或下載／簽章驗證失敗時，仍可使用現有版本與 LAN 分享。

## 第一次啟用

1.0.4 與更早版本没有更新功能，請先手動安裝 1.0.5 一次。後續版本即可在程式內同意更新，不需手動下載或解除安裝。

OTA 採完整安裝包的原地更新，更新時會短暫關閉程式，Room 暫時離線；不是不中斷執行的熱更新。請先完成所有裝置的檔案傳輸。

只有更新檢查與程式下載連接 GitHub，Room 的文字／檔案／配對仍只走 LAN。這次是 Windows 更新功能，Android 繼續使用 [1.0.1 APK](https://github.com/OverGreen996/PocketDrop/releases/download/v1.0.1/PocketDrop-1.0.1-Android.apk)。

## 驗證範圍

- 前端建置、Windows NSIS 建置與 updater 簽章產生通過；13 項既有 Rust 測試通過。
- 更新介面測試：啟動查詢、提示、稍後不下載、同意後下載／保存／安裝順序、已最新、離線重試、驗證失敗不安裝、草稿無法保存不安裝。
- 真實 updater 測試下載已簽署安裝包；拒絕遭修改檔案與不符簽署版本的清單；相同／較舊版本不更新；錯誤版本與離線回報失敗。
- 未在使用者安裝目錄執行完整自我替換測試，不宣稱已驗證所有 Windows 10／11 系統的安装流程。Windows Authenticode 簽章仍未提供，updater 簽章與它不同。

維護者發布流程與私鑰備份要求見 docs/UPDATES.md。私鑰不會上傳 GitHub。
